# KidiPlay

> Une application enfantine, ludique et créative, dans laquelle l’enfant peut jouer, apprendre et s’exprimer librement.

## Vision

KidiPlay est un univers numérique doux, coloré et rassurant destiné aux enfants. L’application réunit trois dimensions complémentaires :

- jouer avec des mini-jeux courts et accessibles ;
- apprendre par la manipulation, l’observation et l’expérimentation ;
- créer librement avec un atelier de dessin et une galerie personnelle.

## Principes

- Interface compréhensible sans lecture complexe.
- Grands éléments interactifs, formes douces et navigation simple.
- Pas de publicité, pas de compte obligatoire, pas d’achat intégré au démarrage.
- Fonctionnement local privilégié.
- Chaque nouvelle fonctionnalité doit rester cohérente avec la charte graphique KidiPlay.
- Le projet avance par tranches courtes, testables et réversibles.

## Première tranche visée

- accueil enfantin ;
- accès aux jeux ;
- premier jeu Memory ;
- atelier de dessin libre ;
- outils de couleur, épaisseur, gomme et effacement ;
- sauvegarde locale ;
- galerie simple.
