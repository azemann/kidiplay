# Contrat de génération — Memory animaux

## Famille

Chien, chat, ours et lapin utilisent la même échelle apparente, la même pose
assise frontale, les mêmes grands yeux bruns et la même lumière. Leur
silhouette et leur couleur dominante restent différentes pour limiter les
confusions chez les enfants de 3 à 5 ans.

| Fichier | Signes distinctifs |
| --- | --- |
| `dog-v01.png` | caramel, longues oreilles tombantes, queue courte |
| `cat-v01.png` | bleu-gris, oreilles triangulaires, queue courbe |
| `bear-v01.png` | brun cacao, oreilles rondes, grandes pattes |
| `rabbit-v01.png` | crème, longues oreilles roses, petite queue ronde |
| `card-back-v01.png` | carte bleue, bord crème et jaune, étoile centrale |

## Contraintes

- corps entier, face caméra et expression rassurante ;
- aucun vêtement, accessoire, texte, décor ou autre personnage ;
- différences perceptibles en silhouette, sans dépendre uniquement de la
  couleur ;
- PNG RGBA avec bords contrôlés ;
- les paires du jeu réutilisent exactement le même fichier, sans régénération.
